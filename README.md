OASIS INFOBYTE — Data Analytics Internship

This repository contains my projects completed during my Data Analytics Internship with OASIS INFOBYTE. 

Completed Tasks

 Level 1 — Task 1: EDA on Retail Sales Data
Exploratory Data Analysis of retail sales data using Python, Pandas, Matplotlib and Seaborn.

 Level 1 — Task 3: Cleaning Data
Data cleaning and preprocessing using Python and Pandas, including missing values, inconsistent values and data validation.

 Level 2 — Task 1: Predicting House Prices with Linear Regression
Built a Linear Regression model to predict house prices and evaluated the model using MSE, RMSE and R².

 Level 2 — Task 2: Wine Quality Prediction
Built and compared Random Forest, SGD Classifier and SVC models to predict wine quality classes.
